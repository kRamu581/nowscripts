# The New Tooling Ecosystem

This lesson introduces the shift towards modern, code-first ServiceNow development utilizing the ServiceNow SDK, GitHub, and Claude Code.

## ServiceNow Studio vs SDK

**ServiceNow Studio**: The traditional, visual, config-first environment. It's best suited for defining form layouts, creating visual flows, and team members who prefer low-code tools.

**ServiceNow SDK**: A code-first, terminal-centric, and git-native approach. It allows developers to:
- Work in their preferred IDE (like VS Code).
- Version-control code natively.
- Pair with AI coding agents to accelerate development.

## AI Coding Agents

**Claude Code**: An AI coding agent that can read your entire project, follow multi-step instructions, and write platform-native code locally. It bridges the gap between natural language requirements and the ServiceNow SDK metadata language.
