# The For Loop

This lesson explains and demonstrates how to use the for loop to run one or more statements multiple times.

Note: `break` and `continue` work here too!

```javascript
for (var i = 0; i < 5; i++) {
 gs.info(i);
}

gs.info('done i=' + i);
```
