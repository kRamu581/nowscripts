# Brownfield Development

You do not have to start from scratch to benefit from the ServiceNow SDK and Claude Code. 

## Working with Legacy Code

You can use the SDK and Claude Code on existing applications (brownfield projects). By pointing the tools at legacy code, you can leverage AI to:
- Explain undocumented logic.
- Help you refactor older scripts into modern Fluent `.now.ts` files.
- Extend older projects with new features much faster than using traditional methods.
