# User Administration

In ServiceNow, an Admin User plays a crucial role in User Administration, ensuring that the platform operates smoothly and securely. 

## Key Responsibilities of an Admin User
* **Create Users:** Admins can create new user accounts with username, password, email, and roles. 
* **Edit User Profiles:** Admins can update user details like name, title, and contact information. 
* **Deactivate/Activate Users:** Manage user accounts by disabling inactive users and re-activating them when needed. 
* **Assign Roles:** Admins assign roles to users based on their job functions. 
* **Create and Manage Groups:** Admins create groups for users with similar roles or functions. 

## Exercise 1 — Onboarding a New Employee

**Situation:** A new employee, Neha Kapoor, joins the company as an HR Executive. She needs a ServiceNow account so she can raise and track her own IT requests. 

**Role required:** admin

### Procedure
1. Navigate to All > User Administration > Users. 
2. Click New. 
3. Fill in the User ID, First name, Last name, Email, Department (HR), and Title (HR Executive). 
4. Click Submit to create the account. 
5. Open the new user record and, in the Roles related list, assign the itil role so she can view and update her own tickets. 
6. Add her to the HR group so she inherits any group-based roles. 

**Result:** Neha can now log in, submit incidents, and track their status using the standard end-user portal.
