
## What is ServiceNow?

![ServiceNow Logo](/images/servicenow-logo.png)

**ServiceNow** is a cloud-based IT Service Management (ITSM) platform that helps companies automate and manage their IT services — all accessible from anywhere via the internet.

* **Cloud-Based ITSM Platform:** Supports IT Service Management and automates common business processes.
* **SaaS Platform:** Software as a Service — consists of modular apps that vary by instance and user.
* **Integrated ITSM Suite:** Covers incident management, problem management, change management, and more.
* **Powerful Ticketing Tool:** Create, track and resolve tickets efficiently.
* **Hosted by ServiceNow:** No need for on-premises infrastructure — ServiceNow manages everything.
* **PaaS Capability:** Also supports Platform as a Service (PaaS) — build custom apps on top of the platform.
* **Accessible Anywhere:** Requires only an internet connection.
* **Used by Service Desks:** Streamlines IT operations and improves customer satisfaction.

## ServiceNow Platform Architecture
ServiceNow is built on a **modular architecture** allowing flexibility and customisation. Each customer gets their own dedicated instance (multi-instance architecture).

### 1. ServiceNow Platform
* **Core Platform:** Provides the foundation — user interface, database, and workflow engine.
* **Modules:** Specialised modules for ITSM, ITOM, HR, CSM, etc.
* **App Engine:** Low-code environment for creating custom applications.

### 2. Integration Layer
* **APIs:** Restful APIs for integrating with other systems and apps.
* **Connectors:** Pre-built connectors for common integrations.

### 3. Data Layer
* **Relational Database:** Stores assets, incidents, changes, and all other data.
* **Data Warehouse:** Centralised repository for analytics and reporting.

### 4. Cloud Infrastructure
* **Scalability:** Scales up or down to match changing business demands.
* **Reliability:** High availability through redundant infrastructure.
* **Security:** Robust measures to protect data and prevent unauthorised access.

## SaaS vs. PaaS: Understanding the Difference

| Aspect | SaaS (Software as a Service) | PaaS (Platform as a Service) |
|---|---|---|
| **What it is** | Ready-to-use application delivered over the internet. | Cloud platform for developers to build and deploy apps. |
| **Control Level** | Limited — customise within set parameters. | More control — manage development environment. |
| **Infrastructure** | Fully managed by provider. | Managed by provider; developer manages apps. |
| **Target Users** | End users / organisations. | Developers. |
| **Examples** | Salesforce, Dropbox, Google Workspace, ServiceNow. | Heroku, AWS Elastic Beanstalk, Google App Engine. |

## ServiceNow Architecture Deep Dive
> **KEY POINT:** ServiceNow uses a multi-instance architecture — every customer gets their own dedicated, isolated instance of the platform for maximum security and customisation.

* **User Interface Layer:** Renders the interface end-users interact with.
* **Application Layer:** Contains all apps/modules: ITSM, HRSD, GRC, ITBM, SecOps, ITFM.
* **Data Layer:** Stores all data: CMDB, Incident DB, Knowledge DB, config tables.
* **Infrastructure Layer:** Underlying hardware, software, and networking resources.

> **REMEMBER:** The specific architecture of a ServiceNow instance will vary depending on the customer's needs and requirements.
