# Providing Context to the AI

AI output quality scales directly with the context provided. If you want high-quality ServiceNow applications generated by Claude Code, you must provide it with clear instructions and background information.

## PRD/GDD (Product Requirements Document)

Always start your development process by writing a Product Requirements Document (PRD) or Game Design Document (GDD). This document should describe:
- The app's core purpose
- User roles and personas
- Data models (tables and fields)
- Business logic and workflows

## CLAUDE.md

The `CLAUDE.md` file is automatically generated by running `/init` in Claude Code. It serves as the AI agent's entry point to your project's context. 
- You can link to your external PRD and architecture docs from within `CLAUDE.md`.
- Keep the `CLAUDE.md` file concise; it should act as an index or a set of primary rules rather than a sprawling novel.
